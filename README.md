# AI RAG Architecture Assistant

AI-powered RAG assistant for querying architecture documentation
using natural language.

## Goal

Build a Java-based RAG application that allows engineers to ask
questions about architecture documentation and receive answers
grounded in the source documents.

## Status

🚧 Work in progress

## Planned Technical Stack

- Java 25
- Spring Boot 4
- Maven
- PostgreSQL + pgvector
- OpenAI API
- Docker
- GitHub Actions****
